# Categories and rules

## Categories

OwnCoffer starts from standard categories (Food, Housing, Transport…) with their sub-categories. You can **rename** them, **add** some or **archive** them: an archived category is no longer offered, and operations already classified keep it.

Transfers between your own accounts and the "Internal movements" category never count in the budget, so that nothing is counted twice.

## How an operation is classified

In this order, the first answer wins:

1. the **household rules** (yours);
2. the **common rules**, shared by the community for the big retailers;
3. your **history**: the category chosen for the same label before;
4. otherwise, the operation stays **to classify**. The AI assistant, if turned on, can then propose a category and a rule, which you accept or not in My advisor.

A choice made by hand is never overwritten by a rule.

## Rules

A rule says: "if the label **contains** (or **starts with**, or **is exactly**) this text, classify it in this category". It can be limited to **debits** or **credits**, to a **range of amounts**, and given a **priority** (the smallest goes first).

The **tester** shows, for a statement label, how it would be cleaned and classified, without saving anything.

The simplest way to create a rule is still the **"Always classify like this"** button in an operation's sheet.
