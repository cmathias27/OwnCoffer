# Premiers pas

OwnCoffer range vos comptes bancaires chez vous : il lit les relevés que vous téléchargez sur le site de votre banque, classe les opérations et prévoit votre solde. Il ne se connecte jamais à votre banque.

## En cinq étapes

1. **Créez vos comptes** (onglet Comptes) : nom, solde de départ et, si vous en avez un, découvert autorisé comme seuil d'alerte.
2. **Importez un relevé** (onglet Import) : téléchargez-le au format OFX, QIF ou CSV sur le site de la banque, puis déposez-le ici. Un aperçu montre ce qui sera ajouté avant d'enregistrer.
3. **Classez ce qui reste** (onglet Opérations, filtre « À classer ») : la plupart des opérations le sont déjà. Pour un commerçant qui revient, « Toujours classer ainsi » crée une règle.
4. **Déclarez ce qui revient chaque mois** : salaire, loyer, abonnements, crédits. Ils entrent dans le solde prévu.
5. **Fixez quelques objectifs** dans le Budget, par exemple pour les courses ou les sorties.

## Ensuite

- Importez un nouveau relevé quand vous voulez, par exemple chaque semaine. Les opérations déjà présentes sont reconnues et écartées.
- L'**Accueil** résume où en est l'argent aujourd'hui et ce qui arrive.
- Le bouton **?** en haut de chaque page ouvre l'aide de cette page.

## Un problème, une idée ?

**« Donner un avis »** (menu du compte sur téléphone, icône en haut sur grand écran) envoie un message à l'administrateur de votre serveur.

## Annuler

Après la plupart des actions, un bouton **« Annuler »** apparaît en bas pendant quelques secondes : il remet les choses comme avant.

## Sur Windows ou Android

Menu du compte → **« Applications »** : les applications Windows et Android à télécharger, dans la version de votre serveur. Quand le serveur est mis à jour, une bannière prévient dans l'application.

Sur Windows et Android, OwnCoffer peut aussi s'utiliser **seul sur l'appareil**, sans serveur : c'est le choix du premier lancement. « Changer de mode » (menu du compte) y revient.
