# Premiers pas

OwnCoffer range vos comptes bancaires chez vous : il lit les relevés que vous téléchargez sur le site de votre banque, classe les opérations et prévoit votre solde. Il ne se connecte jamais à votre banque.

## En cinq étapes

1. **Créez vos comptes** (Argent › Comptes) : nom, solde de départ et, si vous en avez un, découvert autorisé comme seuil d'alerte.
2. **Importez un relevé** (Papiers › Import, ou le bouton **+**) : téléchargez-le au format OFX, QIF ou CSV sur le site de la banque, puis déposez-le ici. Un aperçu montre ce qui sera ajouté avant d'enregistrer.
3. **Classez ce qui reste** (Argent › Opérations, filtre « À classer ») : la plupart des opérations le sont déjà. Pour un commerçant qui revient, « Toujours classer ainsi » crée une règle.
4. **Déclarez ce qui revient chaque mois** : salaire, loyer, abonnements, crédits. Ils entrent dans le solde prévu.
5. **Fixez quelques objectifs** dans le Budget, par exemple pour les courses ou les sorties.

## Se repérer

L'application tient en **cinq rubriques**, en bas sur un téléphone et à gauche sur un grand écran :

- **Accueil** : tout va bien aujourd'hui ?
- **Argent** : comptes et opérations ;
- **Prévoir** : solde prévu, budget, crédits ;
- **Papiers** : factures et import ;
- **Conseiller** : Mon conseiller, avec le nombre de conseils nouveaux depuis votre dernière visite.

Une rubrique à plusieurs écrans les présente en onglets. En haut, le **fil d'Ariane** (par exemple « Prévoir › Crédits ») dit où vous êtes, et le retour ramène à l'écran parent.

- **Rechercher** (la loupe en haut) trouve à la fois des opérations de tous vos comptes, des crédits, des factures et les fonctions de l'application (« exporter », « mot de passe »…). Hors ligne, seules les fonctions sont proposées.
- Le bouton **+** saisit une opération, scanne un ticket ou importe un relevé.
- La **cloche** regroupe les notifications, avec des filtres : alertes, conseils, système.
- **Réglages** (la roue dentée) regroupe le reste : catégories et règles, export, membres, sécurité, applications, Pépite, administration, aide et avis, et l'**affichage** de cet appareil : **mode simple** (masque les fonctions avancées, sans rien désactiver), **grand texte**, **contraste élevé**.
- Sur un téléphone, **glisser une opération** vers la droite la classe, vers la gauche l'ouvre.
- Sous Windows et sur le web, au clavier : `/` pour chercher, `N` pour une nouvelle opération, `1` à `5` pour les rubriques, `?` pour la liste des raccourcis.

## Ensuite

- Importez un nouveau relevé quand vous voulez, par exemple chaque semaine. Les opérations déjà présentes sont reconnues et écartées.
- L'**Accueil** résume où en est l'argent aujourd'hui et ce qui arrive ; la carte **Premiers pas** y suit les trois premières étapes.
- Le bouton **?** en haut de chaque page ouvre l'aide de cette page.

## Un problème, une idée ?

**« Donner un avis »** (dans Réglages) envoie un message à l'administrateur de votre serveur.

## Annuler

Après la plupart des actions, un bouton **« Annuler »** apparaît en bas pendant quelques secondes : il remet les choses comme avant.

## Sur Windows ou Android

Réglages → **« Applications »** : les applications Windows et Android à télécharger, dans la version de votre serveur. Quand le serveur est mis à jour, une bannière prévient dans l'application, et **« Installer »** télécharge la nouvelle version depuis GitHub, la vérifie avec les empreintes publiées et l'installe (Android demande de confirmer ; Windows se ferme et se relance). En mode autonome, « Rechercher une nouvelle version » dans cette page. Rien n'est téléchargé sans que vous le demandiez.

Sur Windows et Android, OwnCoffer peut aussi s'utiliser **seul sur l'appareil**, sans serveur : c'est le choix du premier lancement. « Changer de mode » (Réglages) y revient.
