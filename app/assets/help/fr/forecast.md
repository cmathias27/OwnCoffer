# Prévisions

La courbe du solde jour par jour, sur 30 jours, 90 jours ou un an, pour chaque compte.

## Ce qui est compté

- Les **opérations prévues** : salaire, loyer, abonnements, échéances de crédit. Vous les ajoutez ici ou depuis la fiche d'une opération (« C'est un abonnement »).
- Au choix, les **dépenses variables estimées** (courses, carburant, sorties…) : pour chaque catégorie, la médiane des trois derniers mois complets. Touchez « Dont … de dépenses variables estimées » pour voir le calcul. Le filtre « Dépenses variables » les retire.

Quand une opération réelle arrive, elle est **rapprochée** de l'échéance prévue ; une échéance qui n'arrive pas est signalée **en retard**.

## Alerte de découvert

Si le solde prévu passe sous le **seuil d'alerte** du compte, OwnCoffer vous prévient dans l'application et par courriel. L'alerte ne compte que les opérations prévues, pas les dépenses estimées.

## Simuler un achat

**« Simuler un achat »** : montant, date de l'achat, date à laquelle vous voulez connaître votre solde. Cinq cartes comparent **sans l'achat**, **comptant**, **en 3 fois**, **en 4 fois** et **le mois suivant** : solde à la date choisie, point bas, découvert ou objectif dépassé. Rien n'est enregistré tant que vous ne choisissez pas.

Une prévision reste une estimation : plus vos opérations prévues sont complètes, plus elle est juste.
