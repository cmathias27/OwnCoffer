# 0013 — Licence CC0 pour la base de règles communautaires

**Statut** : Décidé (30 octobre 2026)

## Contexte

Les règles communautaires (« CARREFOUR » → Alimentation) sont tenues dans un dépôt public séparé, `owncoffer-rules`, et livrées avec les mises à jour. Deux licences étaient envisagées : **CC0** (domaine public, aucune condition) ou **ODbL** (obligation de repartager une base dérivée sous la même licence, avec attribution).

Une règle est une correspondance très courte entre un motif de libellé et une catégorie standard : c'est presque un fait, peu protégeable en soi. La valeur de la base tient à sa couverture, donc au nombre de contributions et de réutilisations.

## Décision

La base de règles communautaires est publiée sous **CC0 1.0**.

## Conséquences

- Tout le monde peut reprendre, adapter et redistribuer les règles sans condition, y compris d'autres applications : cela maximise les contributions et l'adoption.
- Aucune obligation d'attribution ni de partage à l'identique : une amélioration faite ailleurs peut ne jamais revenir dans la base ; ce risque est accepté.
- Les contributeurs acceptent explicitement de placer leurs règles sous CC0 (rappel dans le `CONTRIBUTING.md` du dépôt `owncoffer-rules`, en plus du DCO).
- Les règles ne contiennent jamais de donnée personnelle (noms de personnes, numéros de compte, références de prélèvement) : seuls des motifs de commerçants ou d'organismes.
- La licence AGPL-3.0 du code (décision 0004) n'est pas concernée : la base est un jeu de données distinct, compatible avec elle.
